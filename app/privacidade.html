Política de privacidade

O OKL Respostas é usado apenas pela conta dona do canal VENDAS OKL no YouTube.

  • O que acessa: os comentários públicos dos vídeos do próprio canal, pela API oficial do YouTube.
  • O que faz: publica respostas a esses comentários em nome do canal.
  • O que guarda: nada. Nenhum dado de quem comenta é armazenado, vendido ou compartilhado.
  • Como revogar: a dona do canal pode remover o acesso a qualquer momento em myaccount.google.com/permissions.

O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.
